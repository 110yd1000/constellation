Install the security certificate

The apps on this network use their own certificate authority. Install its certificate once so your browser stops showing warnings.

Download certificate
iPhone / iPadOpen the downloaded file, tap Install in Settings, then go to Settings > General > About > Certificate Trust Settings and switch it on.
AndroidSettings > Security > Encryption & credentials > Install a certificate > CA certificate, then pick the file. Some apps ignore user certificates; ask the administrator if one fails.
WindowsOpen the file, choose Install Certificate > Local Machine > Trusted Root Certification Authorities.
macOSOpen the file in Keychain Access and set it to Always Trust.
LinuxCopy it to /usr/local/share/ca-certificates/ and run update-ca-certificates. Firefox keeps its own list.
